Чому необхідно використовувати функцію clearInterval?
Щоб зупиняти попередній таймер щоразу, коли слайд змінюється. Якщо цього не робити, таймери будуть накопичуватися, і слайди почнуть перемикатися занадто швидко та хаотично.

Чому другим параметром хука useEffect ми передаємо [index]?
Щоб ефект перезапускався щоразу, коли змінюється номер поточного слайда. Це потрібно для того, щоб таймер автопрокрутки скидався щоразу, коли користувач вручну натискає кнопки перемикання.
